# FinRAG Analyst - Enterprise Financial Intelligence Chatbot

An enterprise-grade RAG system for analyzing SEC 10-K filings and Q4 earnings transcripts (MSFT, TSLA, JPM) with zero-hallucination guardrails and metadata pre-filtering.

## 📊 Week 3 Tasks Completed (Embeddings & Vector Databases)
* **T5 (Embedding Fundamentals):** Embedded document corpus using OpenAI embedding models.
* **T6 (Vector DB Setup):** Configured local persistent Qdrant vector database instance for semantic search.
* **T7 (Similarity Benchmarking):** Evaluated and configured Cosine distance metric for optimal financial retrieval.
* **T8 (Metadata Filtering):** Implemented payload metadata and multi-parameter filtering for companies and years.

## 🚀 Tech Stack
* **Vector Store:** Qdrant
* **Orchestration:** LangChain (LCEL)
* **LLM:** OpenAI GPT
* **UI:** Streamlit
